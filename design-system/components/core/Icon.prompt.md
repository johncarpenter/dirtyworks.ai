# Icon
Square-cornered glyph from Material Symbols Sharp — the substituted icon set for this brand.

```jsx
<Icon name="folder_open" size={20} />
<Icon name="warning" color="var(--signal-orange)" label="Open gap" />
```

Use sparingly: this identity carries meaning in labels and marks, not icon rows. Weight 500 matches the type; never mix in a rounded or filled set, and never substitute emoji.
