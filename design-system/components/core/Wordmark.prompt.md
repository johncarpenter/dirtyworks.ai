# Wordmark
The brand set in type. No logo files exist yet, so this is the mark everywhere one is needed.

```jsx
<Wordmark size={22} />
<Wordmark size="clamp(40px, 8vw, 96px)" tone="bone" />
```

Lowercase always; the period before `ai` takes signal orange as a registration point. Do not place it in the same corner at the same size on every slide — use the folio system instead.
