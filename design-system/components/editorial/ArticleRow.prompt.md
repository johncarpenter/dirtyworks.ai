# ArticleRow
Row in the NOTES editorial index.

```jsx
<ArticleRow index={1} title="RAG is becoming a feature. Knowledge ownership is still work."
  thesis="Retrieval is commoditising. The source decisions behind it are not."
  evidence="POINT OF VIEW" date="2026-08-25" readingTime="6 MIN" />
```

Always stack these; never wrap them in cards. Thesis is one sentence of argument, not an excerpt.
