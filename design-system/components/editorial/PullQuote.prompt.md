# PullQuote
Instrument Serif italic — the human countervoice against the grotesk architecture.

```jsx
<PullQuote size="lg" attribution="OPERATIONS MANAGER" context="ILLUSTRATIVE">
  Ask Sarah. She knows.
</PullQuote>
```

For statements, questions and counterpoints from people — not for brand slogans, which belong in Declaration. Mark unattributed examples `ILLUSTRATIVE`.
