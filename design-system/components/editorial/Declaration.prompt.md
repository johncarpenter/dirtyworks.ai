# Declaration
Oversized declaration — the hero and section-opener workhorse.

```jsx
<Declaration label="01 / INTERRUPTION" descriptor="MANAGED KNOWLEDGE AND AI OPERATIONS FOR ALBERTA BUSINESSES.">
  Your company knows more than it can find.
</Declaration>
```

2–10 words. Renders uppercase at `--type-display`; drop to `size="h1"`/`"h2"` for section openers. `crop` pulls the word off the left edge — one grid violation per page, so don't set it twice.
