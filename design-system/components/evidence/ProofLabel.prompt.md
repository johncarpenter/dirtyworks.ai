# ProofLabel
Square-cornered evidence chip / status stamp — the brand's most-used graphic device.

```jsx
<ProofLabel status="source" value="03">SOURCE</ProofLabel>
<ProofLabel status="gap">OPEN GAP</ProofLabel>
<ProofLabel status="answer" value="SUPPORTED">ANSWER</ProofLabel>
```

Statuses map to the proof vocabulary: source/permission (blueprint), gap/human (orange), answer/operated (acid), change (ink), owner/neutral (outlined). Never stamp a status onto content that does not carry it, and never encode state by colour alone — the label text is the state.
