# CaseMetric
A number you are allowed to publish, because its baseline, period, method and source travel with it.

```jsx
<CaseMetric value="14" unit="MIN → 2 MIN" label="Time to find the current field procedure"
  baseline="14 min median, 12 events" period="30 days post-launch" method="Timed observation, same question class" source="Launch report / illustrative" hypothesis />
```

Set `hypothesis` on anything not measured with a customer-approved baseline. An unstamped, unsourced number must not ship.
