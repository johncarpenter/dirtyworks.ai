# Redaction
The reveal motif: a heavy bar retracts to expose a more precise statement.

```jsx
<Redaction size="lg" covered="THE AI" revealed="THE OPERATION" open={open} onToggle={() => setOpen(!open)} />
```

On an ink ground pass `tone="bone"` so the bar contrasts with the surface — the default ink bar is invisible on a dark field.

Use once per view, on a real substitution of imprecise language for precise. Not a decorative sweep, and never over body copy.
