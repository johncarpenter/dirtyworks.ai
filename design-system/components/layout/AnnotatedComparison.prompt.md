# AnnotatedComparison
Two fields, one decisive contrast. The left column is struck through; the right carries the position.

```jsx
<AnnotatedComparison leftTitle="A TOOL" rightTitle="AN OPERATED CAPABILITY"
  rows={[{ left: "Connected", right: "Sources approved and owned" },
         { left: "Cancel button", right: "Portable offboarding package", decisive: true }]}
  annotation="Somebody owns Monday morning." />
```

Mark exactly one row `decisive`. 4–8 rows.
