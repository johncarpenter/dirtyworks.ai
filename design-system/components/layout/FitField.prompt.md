# FitField
Bounded fit / non-fit spread for one segment. Excluded decisions are content, not fine print.

```jsx
<FitField label="FIT / 01" segment="Professional services"
  summary="Approved firm methods, templates, software procedures, engagement administration."
  included={["Firm methods and templates", "Software procedures", "Onboarding"]}
  excluded={["Client records", "Professional judgement", "Employment decisions"]} />
```

Two per page maximum — these are editorial spreads, not industry cards.
