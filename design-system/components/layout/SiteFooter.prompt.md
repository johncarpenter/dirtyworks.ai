# SiteFooter
Index-sheet footer: link columns, operating location, oversized wordmark, version device.

```jsx
<SiteFooter location="CALGARY, ALBERTA / CANADA" version="DOC 0.1 / 2026-08-25"
  columns={[{ title: "COMPANY", links: [{ id: "about", label: "About" }] }]} />
```

The version marker is a visual device, not a legal claim.
