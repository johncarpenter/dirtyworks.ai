# CTABand
The hard conversion band that closes a page or chapter.

```jsx
<CTABand folio="11 / CONVERSION" heading="Show us the last answer your team had to chase."
  support="One question domain. A paid, fixed-scope review. A real decision at the end — including stop."
  primary={{ label: "START WITH ONE QUESTION DOMAIN" }} secondary={{ label: "READ THE OPERATING MODEL" }} />
```

`tone="ink"` for page ends, `"orange"` when the band interrupts mid-page. One per page.
